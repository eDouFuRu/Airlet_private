# Airlet

Airlet 是一款 macOS 灵动岛应用：把音乐、歌词、日历、专注计时、通知和常用工具放在屏幕顶部。带刘海的 Mac 会使用贴合刘海的样式；没有刘海的 Mac 或外接显示器会显示可调节宽度的悬浮玻璃岛。

**下载最新版：[Airlet 安装包（DMG）](https://github.com/eDouFuRu/Airlet_private/releases/latest)**

> 当前版本：v1.1.4。需要 **macOS 15 或更新版本**，发布包面向 **Apple 芯片 Mac（M1 及后续机型）**。Intel Mac 未经过验证。无需升级到 macOS 27；macOS 26 可使用系统原生玻璃效果，macOS 15–25 使用系统模糊材质。

## 下载和安装

1. 打开[下载页面](https://github.com/eDouFuRu/Airlet_private/releases/latest)，在 **Assets** 下点击文件名以 `.dmg` 结尾的安装包。当前版本也可[直接下载 Airlet-1.1.4.dmg](https://github.com/eDouFuRu/Airlet_private/releases/download/v1.1.4/Airlet-1.1.4.dmg)。页面上的 **Source code (zip)** 是源码，不能像安装包一样直接使用。
2. 双击下载的 DMG，将 **Airlet** 图标拖进 **应用程序（Applications）** 文件夹。随后从「应用程序」打开 Airlet，而不是一直从 DMG 内运行。
3. 如果 macOS 首次阻止打开：先尝试打开一次，再到 **系统设置 → 隐私与安全性**，找到 Airlet 的提示并点击 **仍要打开**，然后确认 **打开**。本项目的发布包未经过 Apple 公证，因此可能出现这一步。只在确认安装包来自本仓库时继续；详细操作见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

首次启动后，小岛出现在屏幕顶部。Airlet 通常也会在菜单栏显示图标，点击它可进入设置或退出应用。

## 第一次使用

- **打开小岛**：把鼠标移到屏幕顶部中央的小岛位置。无刘海屏默认自动隐藏，鼠标移入后先显示胶囊，稍作停留会展开。也可按 **⇧⌘I** 主动展开。
- **个性化显示**：在菜单栏 Airlet 图标的设置中调整悬停展开延迟、无刘海屏自动隐藏及胶囊宽度。长歌词可选择是否自动扩宽胶囊。
- **多屏使用**：如果只在一块屏幕上看到小岛，请在 **设置 → 通用** 打开「在所有显示器上显示」。每块屏幕会按自己是否有刘海选择样式。
- **音乐和歌词**：播放歌曲后，Airlet 可显示当前媒体、播放控制和歌词。歌词匹配可能访问网络；歌曲切换提示显示时，歌词会暂时让位。
- **其他页面**：展开后切换到日历、文件暂存、工具等页面。番茄钟可在小岛内开始专注计时。

## 权限怎么选

基础小岛和媒体显示不要求一次授予所有权限。需要某项功能时，再按 macOS 提示授权即可。权限可随时在 **系统设置 → 隐私与安全性** 中更改。

| 权限 | 用途 | 不授权时 |
| --- | --- | --- |
| 辅助功能 | 接管音量／亮度按键提示、转显其他应用的通知、暂存区快捷键等 | 这些扩展功能不可用，基础小岛仍可使用 |
| 屏幕录制 | 截屏／录屏工具，以及可选的「根据背景亮度变化的玻璃边缘」 | 基础玻璃效果仍可使用；动态边缘使用中性光效 |
| 日历与提醒事项 | 在小岛中查看日程和提醒 | 对应内容不显示 |
| 摄像头 | 使用镜子工具 | 镜子工具不可用 |
| 通知 | 计时器、闹钟等到点提醒 | 不弹出系统提醒 |

动态玻璃边缘只在无刘海小岛可见时读取附近画面的亮度，不保存录制画面。更改屏幕录制或辅助功能权限后，建议完全退出 Airlet 再重新打开。

## 能做什么

- **媒体与歌词**：播放／暂停、切歌、查看封面与同步歌词。
- **专注与日程**：番茄钟、统计、日历和提醒事项。
- **文件暂存**：拖入文件、截图和图片，稍后再取用。
- **系统工具**：音量、亮度、电源提示，以及可选的截屏、录屏、计时器和闹钟等工具。
- **通知转显**：按应用选择是否在小岛内显示桌面通知及内容预览。
- **悬浮玻璃岛**：无刘海屏可调宽度、透明度和是否自动隐藏；带刘海屏保留原有贴合样式。

## 常见问题

<details>
<summary>安装后看不到小岛？</summary>

确认 Airlet 已从「应用程序」启动；把鼠标移到屏幕顶部中央。无刘海屏默认会自动隐藏。若使用外接显示器，到 **设置 → 通用** 检查「在所有显示器上显示」。

</details>

<details>
<summary>为什么打开时提示无法验证开发者？</summary>

发布包尚未经过 Apple 公证。请核对下载地址是本仓库 Release，再按上方「下载和安装」第 3 步操作。不要下载来源不明的同名应用。

</details>

<details>
<summary>为什么搜索 Airlet 会出现多个结果？</summary>

通常是电脑上同时保留了旧版应用、构建产物或仍挂载着 DMG。日常使用只需将一个正式安装的 **Airlet.app** 放在「应用程序」中，并从那里启动；其余副本可在确认不再需要后自行移除。

</details>

<details>
<summary>一定要开屏幕录制权限吗？会持续录屏吗？</summary>

不需要。不开启时也能使用基础小岛和玻璃外观。截屏／录屏工具需要该权限；可选的背景响应边缘仅在小岛可见时采样附近画面的亮度，不会持续保存视频。

</details>

<details>
<summary>升级 macOS 27 后玻璃会自动变得更好吗？</summary>

Airlet 当前主要在 macOS 26.6.2 上开发和检查。它使用 macOS 26 已提供的原生玻璃 API，不依赖 27 专属接口；macOS 27 的实际观感仍需在对应系统上验证，不能保证仅升级系统就会得到特定效果。

</details>

## 从源码构建

普通用户直接下载 DMG 即可。开发者需要 Xcode 26 或更新版本，打开 `boringNotch.xcodeproj` 并选择 `NotchIslandNext` scheme。项目部署目标是 macOS 15。签名和打包说明见 [LOCAL-SIGNING.md](LOCAL-SIGNING.md)；构建产物与开发机签名私钥不在仓库中。
